# Power BI Dashboard Setup Guide

This guide walks through building the interactive Power BI dashboard using the exported CSV files in `powerbi_exports/`.

## 1. Data Loading
* Open Power BI Desktop.
* Click **Get Data -> Text/CSV**.
* Load all four exported files:
  - `customer_segments.csv`
  - `segment_summary.csv`
  - `segment_category_spend.csv`
  - `targeting_framework.csv`
