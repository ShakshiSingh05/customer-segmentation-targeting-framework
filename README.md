# Customer Segmentation & Targeting Framework
**SQL (SQLite) · Python (Pandas, scikit-learn) · Power BI**

Segments credit card customers by spend, frequency, recency, category mix and tenure, then maps each segment to a recommended offer, channel and KPI.

> **Data note:** All data is **synthetic**, generated by `01_generate_data.py` (seeded, reproducible). No real customer data is used. Findings describe the synthetic data and show the method, not a real portfolio. Spend values are in an arbitrary currency unit.

## Pipeline
| Step | File | What it does |
|---|---|---|
| 1 | `01_generate_data.py` | 5,000 customers, ~535K transactions over 12 months, with injected duplicates and invalid amounts |
| 2 | `sql/01_clean_and_features.sql` | Removes duplicates and non-positive amounts (70 rows), builds per-customer spend, frequency, recency, tenure, category-share features |
| 3 | `02_segmentation.py` | Log-transform + standardise, K-Means; k chosen by elbow + silhouette (k=5, silhouette 0.51) |
| 4 | `03_segments_offers_exports.py` | Names segments from their profiles, builds the targeting framework, charts, and Power BI exports |

Run in order: `python 01_generate_data.py && python 02_segmentation.py && python 03_segments_offers_exports.py`

## Results (synthetic data)
| Segment | % customers | % spend | Profile |
|---|---|---|---|
| Premium Travel & Dining Elite | 14.1 | 49.6 | Highest ticket size, ~46% of spend on travel, longest tenure (~59 months) |
| Everyday Essentials Loyalists | 30.5 | 22.7 | Most frequent, groceries + fuel heavy |
| Digital Shoppers (New) | 22.3 | 22.3 | Newest (~14 months), shopping-led, high frequency |
| Low-Engagement Occasional | 19.9 | 3.3 | Few transactions, low spend |
| Lapsed / Dormant | 13.3 | 2.0 | No transaction for ~218 days on average |

- **14% of customers drive ~50% of spend**, so retention of the premium segment is the top priority.
- **Illustrative scenarios (assumptions, not forecasts):** reactivating 10% of Lapsed customers at their historical average spend, or lifting Low-Engagement spend by 10%.
- The targeting framework (segment → objective → offer → channel → KPI) is in `powerbi_exports/targeting_framework.csv`.

## Limitations
- Segments recover the synthetic groups almost perfectly because the generator created them. This is **not** evidence of real-world accuracy.
- K-Means assumes roughly spherical clusters; on real data, compare with other methods and test stability.
- Offer recommendations are hypotheses; in practice they should be validated with an A/B test.
